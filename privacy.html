Privacy Policy

ReachForge for Gilderow · Effective 14 November 2026

Who we are

ReachForge is a private tool used only by the owner of Gilderow, an Etsy shop selling digital wall art. It runs on the owner's own computer and publishes Gilderow's own artwork to Gilderow's own Instagram, Pinterest and (later) TikTok accounts, after the owner approves each post. It is not offered to other people and has no user accounts.

What data the tool reads

  • Etsy (Gilderow's own shop, read-only): listing titles, SKUs, states and links, so every post links to a live listing.
  • Instagram (Gilderow's own professional account): the account id and username, and the ability to publish posts the owner approved.
  • Pinterest (Gilderow's own business account): board names and existing Pins of that account (to avoid posting the same image twice), and the ability to create Pins the owner approved.

The tool does not read, collect or process data about any other person: no followers, customers, messages, comments, contacts or analytics of other users.

Where data is stored

All data stays on the owner's computer: a local database of posts and a local folder for access tokens. Nothing is stored on a server of ours, because there is none. This website stores nothing and sets no cookies.

Sharing

Data is not sold, rented or shared with anyone. The only transfers are the API requests the tool makes to Etsy, Instagram (Meta) and Pinterest on behalf of Gilderow's own accounts, which those platforms handle under their own privacy policies.

Data deletion

To remove the tool's access and all data it holds:

  1. Revoke the app's access in the platform's settings (Instagram: Settings → Apps and websites; Pinterest: Settings → Security and logins → Apps; Etsy: Account settings → Apps).
  2. Delete the local token files and the local database on the computer running the tool.

For any request about data, write to the contact address below; it is answered within 30 days.
